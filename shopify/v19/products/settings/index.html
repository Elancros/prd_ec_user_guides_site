    Product settings¶

    Open the store, click Configuration, then Products. The section has six headings in the side panel: Matching & Import Rules, New Products, Prices, Categories, Images and Shopify, and two tables: Attribute Mappings and Store Categories.

    Matching & Import Rules¶

    These settings decide what happens to each Shopify variant at import: is it already an Odoo product, should Odoo create it, should Odoo update it?

    Setting What it does
    Match Product By How a Shopify variant finds its Odoo product: Internal Reference / SKU, Barcode, or SKU, then Barcode.
    Company-Specific Products On: products created from this store belong to its company only. Off: they are shared by all companies.
    Auto Import Product On: a Shopify product with no Odoo product is created in Odoo. Off: it is reported in the sync job and skipped.
    Auto Update Product On: imports also update the Odoo products that already exist, only for the values ticked Sync on Update (Import) in Field Mappings.
    Auto Create Attributes On: unknown options (e.g. Color: Red) are created in Odoo. Off: the product waits until you map them in Attribute Mappings.

    How a variant finds its Odoo product¶

    flowchart LR
    V[Shopify variant] --> L{Already linked<br/>in the store layer?}
    L -- yes --> U[Same Odoo product]
    L -- no --> M{Odoo product with<br/>the same SKU / barcode?}
    M -- yes --> K[Linked to it]
    M -- no --> A{Auto Import Product?}
    A -- on --> C[Created in Odoo]
    A -- off --> R[Reported, skipped]
    classDef default stroke-width:2px
    linkStyle default stroke-width:2px

    Once a variant is linked, the link wins: a later change of SKU on Shopify does not create a second product.

    Example

    Odoo has Desk Lamp with Internal Reference LAMP-01. On Shopify, the variant of Desk Lamp has SKU LAMP-01. With Match Product By Internal Reference / SKU, the import links the two: no new product, and Shopify orders for the lamp use your existing Odoo product, its stock and its accounts.

    Products already in Odoo

    If your products are already in Odoo, give them the same SKU or barcode as on Shopify before the first import, and leave Auto Import Product off for that import: products that find no match are reported instead of created twice. Check the report, fix the codes, then import again.

    Two Odoo products with the same code

    When the import creates a product whose Internal Reference or barcode another Odoo product already has (in any company), the product is created and the log names the other product, so you can clean up.

    Attribute Mappings¶

    Shopify › Products › Attribute Mappings (or the table of the section) links Shopify option names and values (e.g. Colour, Rouge) to Odoo attributes and values (Color, Red). Rows created automatically are marked Auto Created: review them once.

    New Products¶

    What a product created from Shopify looks like in Odoo.

    Setting What it does
    Product Type Type of the products created from Shopify: Goods or Service, and Track Inventory for goods.
    Default Product Category Category of new products when no store category applies.

    Track Inventory

    Leave Track Inventory on if Odoo holds your stock: deliveries of store orders then take the goods out of your warehouse, and Export Stock can send the quantities to Shopify.

    Prices¶

    Setting What it does
    Store Prices Where Shopify prices are kept in Odoo, for import and export. Product Sales Price: the product's sales price. Instance Pricelist: one price per variant on the store's pricelist.
    Pricelist The store's pricelist, shown with Instance Pricelist. It must be in the store currency.

    Whether prices are imported or sent at all is set by the Price row of Field Mappings.

    When to use a pricelist

    Use Instance Pricelist when the store currency is not the company currency (the setup checklist asks for it), or when Shopify prices differ from your Odoo sales prices. Example: Odoo sells a chair at 120 EUR to your shops; the EU store sells it at 139 EUR. The pricelist keeps 139 for the store; the sales price stays 120. A warning appears when other stores keep their prices on the same pricelist.

    Order prices never come from these settings: an order always has the price the customer paid on Shopify.

    Categories¶

    Setting What it does
    Import Categories Keeps the Shopify categories in Store Categories and gives new products the matching Odoo category.
    Category Source Which Shopify value is the category: Product Type (free text) or Shopify Standard Category (Shopify's taxonomy).
    Auto Create Odoo Categories On: a Shopify category with no match creates an Odoo category. Off: map it yourself in Store Categories.

    In Shopify › Products › Store Categories, each row links a Shopify category to an Odoo Category. When several store categories use the same Odoo category, tick Use for Export on the one products added to the store layer should get.

    Images¶

    Setting What it does
    Import Images Brings the product and variant images from Shopify. They arrive a few minutes after the products.
    Overwrite Existing Images On: replaces the main image of products that already have one. Off: Shopify images are added; existing main images stay.
    Image Removed on Store Keep in Odoo, or Remove from Odoo (unless another store still uses it).
    Export Images Sends the product images to Shopify with Export to Store and Update on Store, shortly after the products.
    Image Removed in Odoo Keep on Store, or Remove from Store at the next update.

    The images of each store are listed in Shopify › Products › Store Images, with their state.

    Why images come later

    Images are large. Odoo imports the product first, then downloads its images in the background, so a product with thirty photos never slows down the import of the others. A failed image is retried on its own.

    Shopify¶

    Setting What it does
    Product Statuses to Import Import Active Products, Import Draft Products, Import Archived Products: new Shopify products are imported only with a ticked status. At least one is needed.
    Large Import From Above this number of products (default 1,000), Import Products runs in the background in batches: see Bulk Imports. 0: never.
    Default Sales Channels Sales channels (Online Store, Point of Sale…) given to the products added to the store layer. You can change them per product. Fetch Sales Channels reads the list from Shopify.

    Statuses only filter new products

    A product already in the store layer always gets its changes, a new status too, whatever is ticked.

    What happens next

    Bring your Shopify products into Odoo: Import products.
