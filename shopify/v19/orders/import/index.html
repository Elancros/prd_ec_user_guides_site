    Import orders¶

    Import Orders¶

    1. Perform Operation › Import Orders.
    2. Choose From Date, To Date and Date Based On.
    3. Click Execute.

    Order Result
    New, placed after Import Orders From, with a status chosen in Order Settings Created as a quotation, then its workflow runs.
    New, with another status or placed before Import Orders From Not imported; the log says why.
    Already in Odoo Its changes are applied: payments, shipments, refunds, cancellations, edits.
    Uses a value not mapped yet Waits; it continues by itself once you map the value.

    Orders are processed in the background: follow them in Shopify › Activity › Sync Jobs. Many orders? Shopify prepares them in the background: Bulk Imports.

    Orders older than 60 days

    Shopify gives the orders of the last 60 days only, unless the app has the read_all_orders scope (Access scopes).

    Import Specific Order¶

    Perform Operation › Import Specific Order with the order number (e.g. 1001) or its ID (the number at the end of the order's address in Shopify admin). Same rules as Import Orders; an order already in Odoo gets its changes.

    Import orders automatically¶

    Way How
    Webhooks Order Created / Updated and Order Deleted: every new order and every change arrives at once. See Webhooks.
    Scheduler Import Orders in Schedulers, switched on: each run reads what changed since the last one. Keep it, e.g. once a day, even with webhooks: Shopify does not guarantee every event.

    The order in Odoo¶

    Imported orders are in Shopify › Sales › Orders (and in Sales, with the filter Store Orders).

    The Store Order tab of an order shows:

    • Order: Store, Store Order Number and Store Order ID, Sales Channel, the dates on the store, and Open in Store;
    • Status on Store: Store Payment Status, Store Shipping Status, the Order Workflow chosen by Workflow Mapping, Payment Gateways, Risk Level (and Risk Checked once you accepted a risky order), cancelled or deleted on Shopify;
    • Workflow: Store Workflow (Done, Held, Failed…), its message, and Run Workflow to run it again;
    • Amounts on Store: Total in Store Currency, Discount Codes, the credit notes made for Shopify refunds;
    • Shipments: each delivery, its carrier, tracking number and whether Shopify has it (On Store: Sent, Sending, Failed, with the Store Shipment Error); click a line to open the delivery;
    • Store Transactions (payments and refunds).

    Open in Store

    Open in Store opens the same order in Shopify admin: handy to compare when something looks different.
